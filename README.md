# MULENETX

**A Rust-based terminal market intelligence dashboard.**

MULENETX is a keyboard-driven market monitoring application built with Rust and Ratatui. It provides a compact interface for monitoring multiple financial instruments simultaneously.

## Features

- Four-panel chart layout for AAPL, MSFT, NVDA and BTC-USD
- Candlestick charts and technical indicators
- Market watchlist with price changes and sparklines
- Keyboard-driven navigation and chart controls
- Terminal-first interface

## Technology

- Rust
- Ratatui
- Market data integration
- Terminal-based visualisation

## Build from source

Install Rust and Cargo, then run:

```bash
cargo check
cargo run --release
```
